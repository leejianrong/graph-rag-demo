# Fonts

Self-hosted so the page never asks another host for a font. All are licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org), which allows bundling and redistribution.

| file | family | source |
|---|---|---|
| `bricolage-grotesque-latin-600-normal.woff2` | Bricolage Grotesque 600 | `@fontsource/bricolage-grotesque` |
| `ibm-plex-sans-latin-400-normal.woff2`, `-600-` | IBM Plex Sans 400, 600 | `@fontsource/ibm-plex-sans` |
| `ibm-plex-mono-latin-400-normal.woff2` | IBM Plex Mono 400 | `@fontsource/ibm-plex-mono` |

Latin subset only. A name outside it falls back to the system font in the stack.
